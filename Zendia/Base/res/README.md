# Resources

Files Zendia installs and loads at run time:

- `keyboard/`: the shipped keyboard profiles, `standard.toml` (the default) and `vim.toml`. They use the same format as
  the profiles users write.
- `automation-world/`: the scripts that run in each page's Automation World, for vim hints and agents.
- `plugins/examples/`: example plugins.

Each directory is added with the first file it holds.
